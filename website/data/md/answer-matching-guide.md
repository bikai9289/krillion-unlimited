Knowing a fact and entering a recognized game answer are related tasks, but they are not identical. Krillion Unlimited checks a prepared answer bank rather than asking a person to interpret every sentence. A rejection can mean that your response misses the prompt's condition, uses an unsupported name or simply is not included in this site's limited bank.

This guide helps you distinguish those situations without guessing how another website handles the same question. Our Daily and Unlimited dives use this site's independent questions, accepted entries and saved scoring snapshots. A guide for another Krillion service is not a universal answer key.

## First check the answer type

Before changing your spelling, reread the noun in the question. Does it ask for a country, a direction, a utility or a person? A response can be strongly associated with the subject and still be the wrong kind of object.

For example, “name a country with a land border with Mongolia” calls for a country that shares that boundary. A capital city is the wrong answer type even if it is in the region. “Name a utility on the classic US Monopoly board” calls for Electric Company or Water Works, rather than any property you remember buying.

This check is especially useful under the timer because it can rule out a whole group of mistaken candidates quickly. You do not need to search for a more obscure response if the first problem is that you have chosen the wrong category.

## Then check every restriction

Small words define the set. “Four main compass directions” excludes intermediate names such as northeast. “Classic US” specifies a Monopoly version. “Land border” is more precise than “nearby.” A correct answer to a broader question can be wrong for the narrower question actually shown.

Try turning the prompt into a short checklist before typing. For the Monopoly example, the response must be a utility, it must belong to the specified board, and it must be one prepared entry. This habit becomes more valuable as questions introduce awards, symbols, letter counts or named groups.

Avoid solving a different question because its answer is more familiar. Remembering a genuine fact about a themed board or an associated region is useful knowledge, but it does not override the restrictions on the screen.

## Use the canonical name when you know it

The bank stores an accepted name and, for some entries, prepared aliases. Those aliases let particular alternative inputs resolve to the same answer. They do not make every abbreviation or informal description valid.

For the utility prompt, “electric” is explicitly configured as an alias for Electric Company. Water Works does not have an equivalent additional alias in the current record. For the compass prompt, the full words are stored, but the single-letter compass labels are not configured as aliases. Therefore an abbreviation that looks obvious to a human reader can still be an unsafe submission.

The practical habit is simple: enter one complete name when you can. Do not wrap it in a sentence, include two competing guesses or append an explanation. The input field is for a single answer, not a message asking the matcher to infer your intended choice.

## Separate normalization from meaning

The matching code normalizes presentation differences such as capitalization and accents. That makes ordinary typing more forgiving, but it does not create new factual relationships. Normalizing “north” and “North” is different from deciding that northeast is another name for north.

Likewise, removing presentation differences cannot turn a railroad into a utility. When an answer fails, repeatedly changing upper-case letters is unlikely to help if the real problem is the category. Use the available time to reconsider the condition or choose another known entry.

There are also limits to what you should infer from a guide. A displayed alias list documents configured alternatives; it is not an invitation to test every possible shortened phrase during a timed round. Prefer a form you know the bank recognizes.

## A correction suggestion needs confirmation

If the game proposes a spelling correction, read the suggested name. A proposal does not yet mean the answer has been accepted or points have been awarded. Submit again to confirm the suggestion while the round is still open.

Do not confirm automatically if the suggested word is a different answer from the one you meant. Recheck the prompt, inspect the proposal and choose deliberately. The correction mechanism helps with conservative spelling differences; it is not a general explanation engine for any loosely related response.

If an unrecognized answer is rejected, another attempt may still be possible before the deadline. A blank timeout or pass earns zero for that round. Learning when to stop chasing an uncertain interpretation and use a known entry is part of playing the timed game.

## Use the right answer review for the run

Daily provides a shared seven-question challenge for the site's New York date. Unlimited draws a mixed set for each new dive. A dated Daily archive will therefore not necessarily match the seven questions in your Unlimited run.

After completing a dive, use its own answer review to inspect the saved entries and scores. That snapshot matters because new runs can use observed-frequency scoring once the prompt has enough eligible browser choices, while smaller samples use labelled editorial fallback. A static article explaining fallback tiers is not a promise about every future score.

Reading an answer page does not submit an answer for you or change the result already held by the server. The game still requires a recognized submission within the round's timing rules.

## When a genuinely valid response is missing

Our bank is limited. An answer can satisfy a real-world question and still be absent from a prepared list. If that happens, distinguish the factual issue from the game's current acceptance rule. “Not recognized here” is a narrower statement than “false everywhere.”

To document a possible omission, keep the exact prompt, the answer you tried and a reliable source showing why it satisfies all restrictions. Do not include player cookies, credentials or personal details. Use only a support channel actually published on the [Contact page](/contact/); do not guess an email address.
