## Find help for the right game

This answer hub covers krillion-unlimited.app only. It does not claim to publish the official daily answers for krillion.io. Before using a list, check the website, date and game mode: Unlimited questions will usually differ from Daily.

## How to find a valid answer

Read every condition: a country is not a city, a league MVP is not a Finals MVP, and a one-letter chemical symbol is not a one-letter element name. Start with a safe example, then consider another valid entry that is less familiar.

## Why an answer can be rejected

Our matching engine checks prepared answer lists. It normalizes capitalization, spacing and accents, supports stored aliases and proposes conservative spelling corrections. A valid real-world answer can still be absent from the starter list. Rejection means no match was found in this bank, not that the answer is impossible. You can try again before the deadline.

## Spelling corrections and aliases

When a correction is proposed, check the suggested answer and submit again to confirm it. Merely seeing the suggestion does not award points. Some questions accept short aliases, but full names are safer, especially for people and awards.
