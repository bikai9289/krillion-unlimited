# Krillion Unlimited models and game capabilities

Canonical: https://krillion-unlimited.app/models.md

No generative AI model is available or called by this game. The models.md filename follows the agent documentation convention; this is a trivia game, not an AI generation workspace.

## Available workflows
- Daily seven-prompt trivia
- Unlimited randomized practice dives
- Daily and weekly anonymous leaderboards
- Six rarity tiers
- Typo correction with confirmation
- Animated jellyfish and depth feedback
- Synthesized sound effects
- Score and depth report
- Answer review
- Local completed-dive history
- Shareable results

Gameplay and in-app help: English. External AI question links support English and Chinese.

Answers are validated server-side against prepared entries, with normalization, known aliases and conservative typo correction. Reference answer snapshots may differ from the original game in aliases or subsequent edits. Official reference synchronization is disabled. The independent starter bank supplies both deterministic daily prompts and randomized unlimited practice. Each run snapshots its answer set.

No accounts, multiplayer, themed packs, checkout or cross-device account sync is implemented. Practice does not change the saved Daily result. Rankings include completed daily and unlimited runs; one best result per browser and UTC period.
